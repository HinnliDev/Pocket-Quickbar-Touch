# Quick Bar v0.1.0

First public release of **Quick Bar** for Factorio 2.1 and Pocket Foundry.

- Persistent quick-access slots for controller and touch gameplay
- Horizontal and vertical layouts with adjustable size and position
- Native Factorio item filter selection, item counts, and ghost support
- English and Russian interface

**Install:** Download `pocket-quickbar-touch_0.1.0.zip` below and place it in your Factorio `mods` folder without extracting it.
